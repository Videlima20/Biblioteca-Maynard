# Biblioteca-Maynard
A Biblioteca Maynard é um projeto desenvolvido para trabalho de conclusão de curso (TCC) do grupo administrado pelos alunos do 3º Ano do Ensino Médio de Desenvolvimento de Sistemas: Vitor Leandro, Antonio Gabriel, Arnaldo Portella, Yuri Henrique e Isabelly Aparecida, Juntos visamos criar um moderno aplicativo para a biblioteca da escola
